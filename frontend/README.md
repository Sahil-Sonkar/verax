# Frontend

React 19 + Vite + TypeScript + Tailwind app for Verax.

From this directory:

```bash
npm install
npm run dev
```

The dev server runs at [http://localhost:5173](http://localhost:5173) and proxies `/api` to the Spring Boot API on port 8081.

See the root [README](../README.md) for demo login and how to run the API. Full env, Docker, and deploy: [docs/product.md](../docs/product.md).
